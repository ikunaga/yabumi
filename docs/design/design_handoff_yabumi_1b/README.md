# Handoff: 矢書（やぶみ）UI リデザイン — 1b「藍と朱・送り状の帳面」

## 概要
個人開発者向け SNS 運用ツール「矢書」の見た目を作り直す。対象は、デザイントークン、共通部品、今ある 6 画面（PC・スマホ）、これから作る 6 画面の方向性。

## デザインファイルについて
このフォルダの HTML は**デザインの参照用**で、そのまま使う本番コードではない。既存の Next.js 16 + Tailwind CSS v4 のコードベースで、既存の構成と書き方に沿って作り直すこと。
`Yabumi 1b.dc.html` はブラウザで直接開ける（同じフォルダの `support.js` が必要）。ライト・ダークは画面上の Tweaks、またはソースの `theme` プロップで切り替える。

## 忠実度
**ハイファイ**。色・文字・余白・角丸は確定値。今ある画面（03）はこのとおりに作る。「これから作る画面」（04）はレイアウトと部品の使い方の方向性で、機能の詳細は要求資料に従う。

## デザイントークン
`yabumi-tokens.css` をそのまま `src/app/globals.css` に組み込む（`@import "tailwindcss";` の後）。
- `:root` にライトの値、`@media (prefers-color-scheme: dark)` にダークの値。OS 設定に従う
- `@theme inline` で Tailwind のユーティリティにする（例: `bg-surface`、`text-muted`、`border-line`、`bg-primary text-on-primary`）
- 今の `accent`（朱 #c2410c）は **`primary`（藍 #23406e）に置き換える**。朱は `signal`（#b6402a）として「● 予約」「要確認」などの印だけに使い、ボタンには使わない

## 共通部品
- **ボタン**: 主 = `bg-primary text-on-primary`、太字 15px、padding 12×22、角丸 6、高さ 44。副 = 枠線 1px primary + 文字 primary。テキスト = muted。削除 = `bg-danger`、文字は surface 色。無効 = opacity .4。小 = 13px・高さ 32。スマホの主ボタンは横幅いっぱい、高さ 52
- **入力欄**: ラベルは 14px 太字。必須は「必須」（signal 12px）、任意は「任意」（muted 12px）。枠 1px `input`、角丸 6、padding 12×14、16px（スマホは iOS のズームを防ぐため 16px）。フォーカス時は 2px primary。エラー時は 2px danger + 欄の下に 13px・太字・danger のメッセージ。補足は欄の下に 12px muted
- **フォームのエラー**: 送信時に先頭へ「N か所を直してください」の帯（danger-soft 地、1px danger 枠）を出し、各欄にもメッセージ
- **SNS 札**: `bg-primary-soft text-primary`、12px 太字、pill。ロゴは使わず名前で表す（X / Instagram / Facebook / Threads / TikTok / YouTube）
- **状態の印**: `● 予約`（signal）、`✓ 投稿済み`（success）、`○ 下書き`（muted、細字）、`! 失敗`（danger）。13px 太字
- **カード**: surface 地、1px border、角丸 8。見出し行は padding 14×20、15px 太字、下に 1px line。行は 1px line で区切る
- **用語解説**: 用語には `border-bottom: 1.5px dotted primary`。押すと PC はポップアップ（幅 320、pop 地、角丸 8、影あり。用語名 + 読み、説明 13px/1.8、「用語集で見る →」）。スマホは下から出るシート（背景を rgb(15 20 30 / .45) で暗くし、角丸 16、つまみ 40×4、説明 15px、「用語集で見る」は副ボタン）。Esc と外側クリックで閉じる。`aria-expanded` / `role="dialog"` を付ける
- **空の状態**: カード + `bg-ruled`。見出し 17px 太字、説明 14px muted、主ボタン
- **エラー帯**: danger-soft 地、1px danger 枠、角丸 6、14px 太字 danger
- **いまやること**: 各プロジェクト画面の最上部に 1 つだけ出す。primary 地、上に「いまやること ・ 1 / 3」（12px、字間 .15em、on-primary-muted）、タスク名 22px 太字、説明 14px、右に反転ボタン（on-primary 地 + primary 文字）。下に 3 段階の行（今の段階は太字）
- **ナビ（PC）**: 左のサイドバー（幅 220、nav 地）。上からロゴ（ルビ付き）、プロジェクト切替（1px nav-active 枠）、項目（概要 / 投稿をつくる / カレンダー / 指標 / AI と相談 / ロードマップ）。選択中は nav-active 地 + nav-strong 太字、角丸 6、padding 10×12。プロジェクト一覧・作成画面はサイドバーなしで、上部バー（高さ 64、surface 地）
- **ナビ（スマホ）**: 下のタブ 5 つ（概要 / 投稿 / 予定 / 指標 / 相談）。高さ 72、選択中は上に 2px primary の線 + primary 太字。ロードマップは概要の中から開く
- **ロゴ**: 「矢書」には必ず `<ruby>` で「やぶみ」を振る（rt は 9px 前後、muted、字間 .2em）

## 画面
`Yabumi 1b.dc.html` の 03・04 を参照。PC は幅 1280、スマホは幅 375 で描いている。

### 03 今ある画面
1. **トップ（未ログイン）**: PC は左に見出し 54px（Zen Kaku）+ 副題 + 主ボタン「はじめる（無料）」+ 1〜3 の悩みと解決（罫で区切った表）、右（幅 500）に「送り状」の見本カード（1 つの文面が各 SNS に予約される様子）。スマホは縦に積み、送り状は 3 行に縮める
2. **新規登録・ログイン**: PC は左右 2 分割で、左は nav 地に「最初にやることは 3 つだけ」、右に幅 400 のフォーム。パスワードの補足は「8 文字以上。あと N 文字です。」のように残りの文字数を出す。ログインのエラーは先頭のエラー帯 + パスワード欄を danger 枠に
3. **プロジェクト一覧**: PC は表（アプリ / どんなアプリか / ストアページ / つないだ SNS / 次にやること）。「次にやること」はプロジェクトごとの次の段階へのリンク。空の状態はスマホ版を参照
4. **プロジェクト作成・編集**: 幅 680 のフォームカード。右の欄に、選択中の欄の補足（用語の説明）を出す。ストアページの 2 欄は PC で横並び
5. **プロジェクト詳細**: 見出し（アプリ名 32px + 説明）→「いまやること」→ 2 列のカード（予約中の投稿 / このアプリについて）
6. **用語解説**: 5 の中で KGI のポップアップ（PC）とシート（スマホ）を表示している

### 04 これから作る画面（方向性）
- **投稿作成**: 左に下書き（罫線の地紋、文字数、AI っぽさの指摘数）+ 画像・動画を置く場所。右に「送り先と文面の調整」の表（SNS ごとに選択、文字数 / 上限、状態: OK・画像が必要・動画が必要）+ 選んだ SNS のプレビュー。下に固定バー（送る日時、下書き保存、「N つの SNS に予約する」）
- **カレンダー**: PC は週の 7 列で、今日の列は surface2 地 + 上に 2px primary。チップは左に 3px の線（予約 = signal / 投稿済み = success で表示回数も出す / 下書き = 点線枠）。スマホは日付ごとの縦リストで、注意点（例: Instagram の画像が未設定）を signal で出す
- **AI ネタ出し・AI っぽさチェック**: 左に案のカード（選択中は 2px primary 枠）、右に編集欄。AI っぽい表現は signal-soft 地 + 2px signal の下線で示し、下に「表現 / 理由 / 操作（消す・置きかえる）」の表
- **指標ダッシュボード**: 表示回数 → ストアページ到達 → ダウンロード → 課金 を 1 枚のカードに 4 列で並べ、それぞれに前の段からの割合を出す。下に「読み方」の帯（primary-soft）で数字の意味と次の一手を平易に書く。SNS ごとの表
- **AI と相談（壁打ち）**: 左がチャット（AI は surface カード、自分は primary 地）。AI の返答に選択肢のボタンを付ける。右（幅 360）に「決まったこと」（KGI / KPI）を出し、ロードマップへ反映する
- **ロードマップ**: 右上に KGI の進捗バー（86 / 1,000、残り日数）。段階の表（完了 ✓ success / 進行中 = primary-soft 行 + 進捗バー / これから = muted）

## 振る舞い
- テーマは OS 設定に従う（`prefers-color-scheme`）。手動の切り替えは不要
- ホバー: 主ボタンは primary を少し暗く（`color-mix(in oklch, var(--primary), black 12%)`）。行やカードのリンクは下線。トランジションは 120ms ease-out 程度
- フォーカス: 2px primary の outline、offset 2px
- スマホの用語解説シートは下からスライド（200ms ease-out）
- フォームの検証: 送信時に全欄を検証し、先頭に件数の帯を出して最初のエラー欄へフォーカス。URL 欄は `https://` で始まること、アプリ名は必須
