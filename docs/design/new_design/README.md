いまの正です。前の正（[1b「藍と朱」](../design_handoff_yabumi_1b/README.md)）は古いものとして残しています。

## 考え方

- 白〜うすい灰の地に、白い面（カード）を薄い 1px の枠で置きます。カードに影は付けず、影はポップアップだけにします。
- 押すものは黒です。色は「状態」と「SNS」を見分けるためだけに使い、飾りには使いません。
- 数字は大きく太くし、桁をそろえます（`num`）。前と比べて上がったら緑の ▲、下がったら赤の ▼ にします。
- 上の横並びのメニューで、いまどこにいるかを太字で示します。

## トークン

色は必ずトークンのクラス（`bg-surface`、`text-muted`、`border-border`、`bg-primary text-on-primary`、`bg-sns-x` など）で指定し、色コードを画面に直接書きません。

名前は前の版から引き継ぎ、値だけを替えました。そのため、画面のクラスはそのままで新しい見た目になります。

### ダーク

見本にダークはないので、同じ考え方で作りました。地はほぼ黒の灰、面はそれより一段明るい灰です。押すもの（ボタン・選んだ印など小さなもの）は白に近い色に反転し、SNS と状態の色は明るめにします。大きな面は反転させません（暗い帯は `band`。`bg-primary` を大きな面に使わない）。値は `globals.css` の 2 か所（OS の設定と、切り替えボタンで選んだ `data-theme="dark"`）にあり、`tests/theme-tokens.test.ts` で一致を確かめます。

## メニュー（枠）

- プロジェクトの中（PC、`ProjectShell`）: 上の帯は高さ 56 で、白地に下の枠を引きます。左から次の順に並べます。
  - ロゴ
  - プロジェクトの切り替え（丸い札）
  - 5 項目「概要・投稿・カレンダー・分析・AI と相談」
  - 「その他 ▾」（アカウント設計・ネタ帳・短縮リンク・ロードマップ）
  - 右端に「＋ メモ」とアカウントの丸（ダーク・ログインと退会・ログアウト）
  - 「その他」の画面を開いているときは、「その他」の代わりにその画面の名前を太字で出します。
- プロジェクトの中（スマホ）:
  - 上の帯に、ロゴ・プロジェクト名・「≡ メニュー」（全部の画面・ダーク・アカウント）。
  - 下のタブは 5 項目（印と字。相談は「相談」）。
  - 「＋ メモ」は右下に浮かせます。
- 項目の並びと名前は `src/components/nav/project-nav-items.ts`（`main: true` が 5 項目）。
- プロジェクトの外（`TopBar`）:
  - PC は、ロゴ・パンくず・＋ メモ・アカウントの丸。
  - スマホは、ロゴ・ダーク・「≡ メニュー」。戻るだけの帯は「← 戻る」と画面名。
- ログイン前（`(auth)/layout.tsx`）: 左に白い面（最初にやることの 4 段）、右にフォーム。

## ロゴ

- 矢のマーク ＋ 小文字の「yabumi」です（D ミニマル）。ロゴの下の英字の一言（ONE ARROW, EVERY FEED）は見本だけのもので、画面には出しません。
- 画面の文言・`<title>`・メールの差出人の名前は「矢書」のままです。ロゴだけを yabumi にします。
- マークは SVG で、線だけで描きます（`LogoMark`、色は文字の色）。形は `LOGO_MARK_PATH` の 1 か所にあります。
- 色はロゴの墨（`logo`）で、押すもの（黒）とは分けています。
- 作るもの: `node scripts/build-brand-assets.mjs` で、次のものを作り直します。
  - favicon（16・32・48）。16px はマークを大きく・線を太くして判別できるようにしています。
  - icon、apple-icon、PWA のアイコン（maskable はマークを小さめ）
  - OGP 画像
  - メールのロゴ（`public/icons/email-logo.png`）
- Supabase のメール（`supabase/templates/*.html`）は、ロゴを画像で出し、色を新しいトークンにそろえています。

## 使い分けの決まり

- 押すものは黒（`bg-primary`）です。二番手は白地に灰の枠（secondary）を使います。色付きのボタンは作りません（危険な操作の赤だけは例外）。
- 注意の印（`signal`、琥珀）は「● 予約」「要確認」「遅れそう」「必須」などの印だけに使い、ボタンには使いません。
- SNS の色は、その SNS を表すときだけに使います（印・横棒・カレンダーの札）。
- 上がった・下がったは `Delta` で表し、緑と赤を直接書きません。
- 数字には `num` を付けます。
- まだ作っていない機能へのボタンとメニューは、押せない状態で「準備中」と出します。
- 用語は前の版と同じです（投稿済み、つなぐ／外す、削除する・取り消す、カレンダー、投稿をつくる、短縮リンク、追いかける数字）。メニューの「指標」は「分析」に改めました。
