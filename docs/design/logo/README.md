# 矢書のロゴ

- **元の画像**: `yabumi-logo-2a-horizontal.png`（横組み 2808×1200）、`yabumi-logo-2a.png`（縦組み 1864×1200）。オーナーが用意したもの（2026-10-05）。消さない・上書きしない
- **中身**: 明朝体の「矢書」（濃い紺）に、灰色のふりがな「やぶみ」。右下に朱の角印「文」（白抜き）
- **色**: どれも矢書のトークンと同じ。文字 #1b2333（fg）、角印 #b6402a（signal）、背景 #f2f2ee（bg）
- **注意**: PNG には生成りの背景と角丸が焼き込まれている（角だけ透明）。そのまま画面に置くと、ダークで背景が浮く

## どこに何を使っているか

| 使い道 | ファイル | 作り方 |
|---|---|---|
| ファビコン（16・32・48） | src/app/favicon.ico | 角印の「文」を取り出し、朱の角丸の正方形に置く。小さいので字を 12% 大きく |
| ブラウザのアイコン（512） | src/app/icon.png | 同上（角は透明） |
| iPhone のホーム画面（180） | src/app/apple-icon.png | 同上（角は iOS が丸めるので四角いまま） |
| PWA（192・512・maskable） | public/icons/*.png、src/app/manifest.ts | 同上。maskable は円に切り抜かれても欠けないよう字を 78% に |
| OGP・X のカード（1200×630） | src/app/opengraph-image.png、twitter-image.png | 横組みを、焼き込まれた角丸の外を除いて生成りの地に置く |
| 画面のロゴ（トップ、ログイン、サイドバー、上部バー） | src/components/brand.tsx | 画像は使わない。文字を組み（ふりがな必須）、角印はトークンの色の部品（Seal）で描く |

生成物は `node scripts/build-brand-assets.mjs` で作り直せる。元の PNG を差し替えたら実行し直す（角印の位置が変わったら、スクリプトの SEAL の値も直す）。

## 扱いの決まり

- **ふりがな**: 「矢書」には必ず「やぶみ」を振る（handoff の README のとおり）
- **角印「文」**: 朱（signal）を使ってよいのは、印だからこそ。朱をボタンや面に広げない（CLAUDE.md）
- **最小の大きさ**: 画面のロゴは文字 19px（sm）まで。角印は 13px 以上（それより小さいと「文」が読めない）。アイコンは 16px でも角印だけにして使う（「矢書」の文字は入れない）
- **余白**: ロゴのまわりに、角印 1 つ分以上の余白をとる。他の要素と詰めない
- **ダーク**: 画面のロゴは、文字は fg（ダークでは明るい色）、角印は signal（ダークでは明るい朱）の地に surface（ダークでは暗い色）で字を抜く。トークンの切り替えに任せ、ダーク用の画像は作らない。画像（OGP など）は生成りの地ごと見せるので、ダークでもそのまま
- **やらないこと**: 背景が焼き込まれた PNG を画面にそのまま置く／角印の色を変える／「矢書」と角印の位置を入れ替える／ロゴを斜めにしたり影を付けたりする
