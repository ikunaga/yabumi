## 3. 表に載せず、確認役が見るもの

見つける形を決められない、または言葉そのものは悪くないもの。ja-copy-reviewer（.claude/agents/ja-copy-reviewer.md）が文の意味から見る。

- 英字の内部名（kind・slot・format_id など）が画面に出ていないか
- マーケティングのカタカナ語（エンゲージメント・インプレッション・ファネルなど）に、`<Term>` の解説が付いているか
- 「シリーズ」「フォーマット」「ネタ帳」など機能の名前を、初めて出るところで説明しているか
