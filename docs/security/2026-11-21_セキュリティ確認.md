## 問題がなかった主なもの

- 新しい表（auto_post_holds・auto_samples）の RLS・列の grant・書けるのが service_role だけ。テストあり
- security definer の関数は、すべて search_path と revoke・必要な grant の組。中だけで使う関数（ai_budget_check・ai_budget_status_of・operator_*・auto_post_held・format_var_modes など）を利用者は呼べない
- 利用者が呼ぶ関数は auth.uid() で判定し、未ログインを断る。上限の数は関数の中で固定。p_scope_owner・p_as_of は service_role だけ
- save_auto_plan: format_var_modes は利用者から受け取らない。format_vars は形・長さ・自分で入れる変数との一致を DB で確かめる
- post_format_rounds の移し替えのあとの grant と RLS。project_step_flags は security invoker
- AI の使える量の読み取りは本人の分だけ・用途は決まった一覧だけ・金額は出さない
- 相談の返事は条件つきの update で二重に作れない。予約は reserve_ai_usage のまま
- 偽の AI・LINK_DOMAIN_TEST_SERVER は本番で使わない。本物の Vercel のトークンを偽の宛先に送らない
- 自分のドメイン: 持ち主の確認・入力の確かめ（IP・localhost・予約のドメインを断る）・DoH の宛先は固定・probe はリダイレクトを追わない・ジョブの合言葉は timingSafeEqual で fail-closed
- 通知: 宛先の URL はプッシュのサービスだけ・押したときの URL は同じオリジンだけ・VAPID の秘密の鍵は画面に出ない・ログアウトで端末を外す
- 運営者の画面は運営者でなければ 404（環境変数がなければだれも通さない）
- 依存は @napi-rs/canvas 1.1.0（版を固定・ロックファイルあり）。NEXT_PUBLIC_ の変数は増えていない
