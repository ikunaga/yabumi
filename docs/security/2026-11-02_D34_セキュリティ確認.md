## 問題がなかったと確かめた主なもの

- **新しい 2 つの表（project_destinations・project_outcomes_daily）の RLS**: 本人だけ。insert・update の WITH CHECK で、owner と project の持ち主の両方を確かめている
- **grant**: authenticated に、ポリシーと同じ必要な操作だけ。anon にはない
- **トリガー関数**: invoker で動き、search_path を決めてあり、public・anon・authenticated から revoke 済み
- **projects の更新**: 持ち主だけ。product_type を変えても、他人には影響しない
- **server action**: どれもログインと入力を確かめ、利用者の権限で書く。admin を使うところは owner_id で絞っている
- **ログインの確かめ（getClaims）**: exp と署名を確かめる。React の cache は 1 リクエストの中だけ
- **ストアの取り込みの絞り込み**（product_type = app を問い合わせの段で）: 正しく絞れていて、他人のものと混ざらない
- **CRON_SECRET**: 完全一致で確かめている
- **ネタ帳の画像のパス**: サーバーが作る（利用者の入れた値を使わない）
- **短縮リンク**: 行き先を isValidDestination で確かめる
- **AI に渡すもの**: 決まった値と、本人のものだけ
- **NEXT_PUBLIC_ の環境変数**: 増えていない
