# 矢書（やぶみ）デザイン依頼書

> この依頼をもとにしたデザインは [design_handoff_yabumi_1b/](design_handoff_yabumi_1b/README.md) に届き、2026-10-03 に実装済み。下の「今のデザイントークン」と screens/ のスクリーンショットは依頼時点（作り直し前）のもの。

Claude Design に渡すための資料。今の画面は [screens/](screens/) にある（ライト・ダーク × PC・スマホ）。

## 1. プロダクト

個人開発者が、自分のアプリを SNS で広めるためのツール。
複数の SNS への一括投稿・予約投稿、AI によるネタ出し、効果測定、マーケティングの学習支援をひとつにまとめる。

詳しくは [要求資料](../requirements.md)。

## 2. 使う人

- 個人でアプリを作っている開発者。マーケティングや SNS に慣れていない
- アプリ開発に時間を使いたいので、SNS 運用には時間をかけたくない
- 専門用語に抵抗がある。使ううちに知識が身についてほしい

## 3. 名前とブランド

- 名前は「矢書」、読みは「やぶみ」。矢に手紙を結んで射ち込む「矢文」が由来（[NAMING.md](../../NAMING.md)）
- 初見で読めないので、ロゴや見出しには必ず「やぶみ」のふりがなを添える
- 狙った相手へ、離れた場所から、一斉に文を届ける、というイメージ
- 今は墨色と朱色を基調にしているが、変えてよい

## 4. デザインで大事にしたいこと

1. **開いた瞬間に次にやることがわかる**: 使う人は時間をかけたくない。迷わせない
2. **素人を置いていかない**: 専門用語には解説を添える。今は用語をクリックすると説明が開く
3. **AI っぽい、量産型の SaaS に見えない**: 和の名前らしい、手触りのある落ち着いた見た目にしたい
4. **スマホでも使える**: 移動中に予約投稿を確認する、といった使い方を想定

## 7. 技術的な制約

- Next.js 16 + Tailwind CSS v4 で実装する。色・角丸・影などは CSS 変数（デザイントークン）として受け取りたい
- ライトとダークの両方。OS の設定に従う
- 日本語が主。フォントは今はシステムフォント（ヒラギノ、Noto Sans JP）。Web フォントを使う場合は日本語の読み込みサイズに注意
- 運用費は月 3,000 円以内なので、有料のフォントやアイコンは避けたい
